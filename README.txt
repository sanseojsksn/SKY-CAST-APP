SKYCAST WEATHER DASHBOARD

1. Open script.js in a text editor.
2. Replace YOUR_OPENWEATHERMAP_API_KEY with your own OpenWeatherMap API key.
3. Save all files in the same folder.
4. Open index.html in a browser. For browser geolocation, localhost or HTTPS is recommended.

Get an API key: https://openweathermap.org/api
Note: Weather data requires an internet connection and an active API key. Never publish your API key in a public repository.

Area search update: Search now uses OpenWeatherMap Geocoding API first, so you can search local areas/neighbourhoods as well as cities. Try “Najafgarh, Delhi” or “Dwarka, Delhi”.
